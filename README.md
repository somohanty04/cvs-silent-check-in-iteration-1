# CVS Silent Check-In: Iteration 1 prototype

A clickable version of the Iteration 1 screens for the CVS Silent Check-In concept. It covers the happy path only: notice silent check-in, check in, wait, message the pharmacist, restock with in-store coupons, confirm one combined order, and collect at the register.

Live prototype: https://somohanty04.github.io/cvs-silent-check-in-iteration-1/

Everything is in `index.html`. Each screen is a `<template>`, and a small script handles navigation and the interactive bits (communication chips, Add buttons, quantities, rating).
